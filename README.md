# LibraCore — Library Management System

A fully functional front-end Library Management System built with **HTML, CSS and vanilla JavaScript only**.

## Features
- Dashboard with live statistics
- Book management: add, edit, delete and search
- Member management: add, edit, delete and search
- Issue and return books
- Automatic available-copy updates
- Due dates and overdue status
- Transaction filters
- Category analytics
- Printable reports
- Responsive layout for desktop, tablet and mobile
- LocalStorage persistence — no backend required

## Run
Open `index.html` directly in a browser.

All data is stored locally in the browser using `localStorage`.

## Project structure
- `index.html` — application structure
- `styles.css` — complete responsive styling
- `script.js` — application logic and local data storage
